# Jackson Hospital Website

A professional, modern, fully responsive hospital website built with HTML5, CSS3, Bootstrap 5, and modern frontend libraries. Designed for static hosting on GitHub Pages or any web server.

## Features

- **Premium Healthcare Design** – Clean white background with navy blue, medical blue, and subtle green accents
- **Fully Responsive** – Works seamlessly on mobile, tablet, and desktop
- **8 Complete Pages**:
  - Home
  - About Us
  - Medical Services
  - Our Doctors
  - Appointment Booking
  - Contact Us
  - Patient Information
  - FAQ
- **Interactive Features**:
  - Sticky navigation
  - Appointment form with validation & SweetAlert2 notifications
  - Contact form with validation
  - Service search functionality
  - Animated counters
  - Swiper testimonials carousel
  - AOS scroll animations
  - FAQ accordion
  - Back-to-top button
  - WhatsApp floating contact
- **SEO Friendly** – Semantic HTML, meta descriptions, proper headings
- **Accessible** – Semantic structure, alt texts, ARIA labels where appropriate

## How to Use

1. Clone or download this repository
2. Open `index.html` in a browser, or
3. Deploy the entire folder to GitHub Pages, Netlify, Vercel, or any static host

No build step required. All libraries are loaded via CDN.

## Customization

- Update contact details in all HTML files and the footer
- Replace Unsplash image URLs with your own assets in the `images/` folder
- Modify colors in `css/style.css` under the `:root` variables
- Add real Google Maps embed in `contact.html` (replace the placeholder)

## Browser Support

Modern browsers (Chrome, Firefox, Safari, Edge). Bootstrap 5 and the used libraries provide excellent compatibility.
